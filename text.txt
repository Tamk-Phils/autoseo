BUILD AN AUTONOMOUS AI SEO ENGINE
Build a production-ready SaaS web application called [SEO ENGINE NAME].
The platform is an AI-powered autonomous SEO optimization engine. Its purpose is not merely to give users an SEO score or list problems. A user should be able to enter the URL of a website, allow the platform to crawl and analyze it, connect their Google Search Console account when available, identify the highest-impact SEO opportunities, generate recommended fixes, and—where the user has explicitly authorized it—apply safe SEO improvements automatically.
The application must be designed as a serious SaaS product capable of eventually competing with products such as Ahrefs, Semrush, Screaming Frog, Surfer, and similar SEO platforms.
Do NOT build a simple mockup, static dashboard, fake analytics system, or collection of hardcoded SEO scores. All major functionality must be architected for real implementation.

1. CORE PRODUCT CONCEPT
The primary workflow is:
USER ENTERS WEBSITE URL ↓ SYSTEM VALIDATES WEBSITE ↓ SYSTEM CRAWLS WEBSITE ↓ SYSTEM DISCOVERS PAGES ↓ SYSTEM ANALYZES TECHNICAL SEO ↓ SYSTEM ANALYZES ON-PAGE SEO ↓ SYSTEM ANALYZES CONTENT ↓ SYSTEM ANALYZES INTERNAL LINKING ↓ SYSTEM ANALYZES INDEXABILITY ↓ SYSTEM CONNECTS SEARCH CONSOLE DATA ↓ SYSTEM IDENTIFIES KEYWORDS AND SEARCH OPPORTUNITIES ↓ SYSTEM ANALYZES COMPETITORS ↓ AI SEO ENGINE PRIORITIZES PROBLEMS ↓ AI GENERATES RECOMMENDATIONS ↓ USER CAN APPROVE RECOMMENDATIONS ↓ SYSTEM APPLIES AUTHORIZED CHANGES ↓ SYSTEM RE-CRAWLS WEBSITE ↓ SYSTEM VERIFIES CHANGES ↓ SYSTEM MONITORS SEARCH PERFORMANCE ↓ SYSTEM CONTINUOUSLY FINDS NEW OPPORTUNITIES
The central philosophy is:
Don’t just tell users what is wrong with their website. Tell them what matters most, explain why, recommend the solution, and where authorized, execute the solution.
